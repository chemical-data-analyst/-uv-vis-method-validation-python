Validation of an Analytical UV-Vis Method Using Python

Présentation du projet

Ce projet porte sur la validation d'une méthode analytique par spectrophotométrie UV-Visible (UV-Vis) à l'aide de Python.

L'objectif est d'analyser des données simulées, de construire une courbe d'étalonnage et d'évaluer plusieurs paramètres de validation analytique.

Objectifs

- Construire une courbe d'étalonnage.
- Effectuer une régression linéaire.
- Calculer le coefficient de détermination R².
- Déterminer la concentration d'un échantillon inconnu.
- Évaluer la précision et l'exactitude.
- Calculer les limites de détection (LOD) et de quantification (LOQ).
- Générer un rapport Excel automatisé.

Outils utilisés

- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- Excel

Résultats obtenus

- Concentration calculée de l'échantillon inconnu : 6.81
- Taux de récupération (Recovery) : 99.4 %
- Coefficient de variation (CV) : 0.2635 %
- Erreur relative : 0.6 %
- Limite de détection (LOD) : 0.20625
- Limite de quantification (LOQ) : 0.625

 Project Overview

This project focuses on the validation of an analytical method using UV-Visible (UV-Vis) spectrophotometry with Python.

The objective is to analyze simulated data, build a calibration curve, determine an unknown sample concentration, and evaluate analytical validation parameters.

Main Tasks

- Calibration curve construction.
- Linear regression analysis.
- Calculation of the coefficient of determination (R²).
- Unknown sample concentration determination.
- Precision and accuracy evaluation.
- Limit of Detection (LOD) and Limit of Quantification (LOQ) calculation.
- Automated Excel report generation.

Tools

Python, Pandas, NumPy, Matplotlib, OpenPyXL and Excel.

Key Results

- Unknown sample concentration: 6.81
- Recovery: 99.4%
- Coefficient of Variation: 0.2635%
- Relative Error: 0.6%
- LOD: 0.20625
- LOQ: 0.625

Dataset Note

All datasets and measurements used in this project are simulated for educational purposes. They do not represent real laboratory measurements.
